# Obstacle Escape 🎮

**Genre:** Arcade / Dodge Game  
**Engine:** Unity  
**Language:** C#

Obstacle Escape is a fast-paced arcade dodging game where your goal is to survive and reach the end of the level without getting hit by dangerous traps. With multiple obstacle types and a challenging handcrafted environment, quick reflexes and smart movement are the key to victory!

---

## 🧩 Gameplay Overview

Navigate through a hazard-filled stage using simple WASD controls.  
Each obstacle behaves differently, requiring timing, awareness, and strategy.

---

## 🧱 Obstacle Types

- **Spinning Obstacles** — Rotate in place, demanding precise timing.
- **Targeting Obstacles** — Move toward the player and track their position.
- **Standing Obstacles** — Static blocks that create tight navigation zones.

---

## 🎮 Controls

| Key | Action      |
|-----|-------------|
| W   | Move Up     |
| A   | Move Left   |
| S   | Move Down   |
| D   | Move Right  |
